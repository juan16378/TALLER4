# Sistema de login con reconocimiento facial

Proyecto full-stack: **Django** (frontend, sesion de usuario + UI) y
**FastAPI** (backend, autenticacion JWT + reconocimiento facial con OpenCV).

## Estructura

- `backend/` - API FastAPI (auth, reconocimiento facial, base de datos).
- `frontend/` - Sitio Django (vistas, plantillas, captura de camara).
